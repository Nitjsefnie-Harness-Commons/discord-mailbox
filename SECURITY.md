# Security policy

## Reporting a vulnerability

Report a vulnerability privately, through GitHub's private vulnerability
reporting: open the repository's Security tab (GitHub labels it Security and
quality), choose Report a vulnerability and fill in the form. The form is also
at <https://github.com/Nitjsefnie-Harness-Commons/discord-mailbox/security/advisories/new>.

Do not open a public issue for a vulnerability.

## Supported releases

Only the latest release receives security fixes. A fix ships as a new patch or
minor release. A release is a `v<version>` tag that the `release` workflow
publishes.
